# Career Pilot implementation roadmap

This plan turns the current prototype into a dependable, polished career planning web app while preserving its gameful roadmap and low-cost AI direction.

## Delivery sequence

| Step | Scope | Completion evidence | Status |
|---|---|---|---|
| 1 | Authentication and security foundation: use real Supabase sessions only, secure email verification, restrict profile/gamification writes, and authorize privileged functions from the session. | No local identity fallback; OTP/password sign-in creates a Supabase session; RLS and function ownership checks are explicit. | Code implemented; DB application/verification pending local Docker |
| 2 | Persistent product data: make profiles, goals, roadmaps, milestones, tasks, quiz attempts, skills, CVs, interview attempts, and coach history account backed. Add loading, empty, and error states. | Core records survive refresh, sign-out/sign-in, and a second device; no business state depends on generated component state. | Code implemented; live database verification pending |
| 3 | Core career journey: reliable role catalog/templates, realistic capacity-aware planning, checkpoint scoring, task progression, streaks, achievements, and transactional re-planning. | A new account can create a feasible plan and complete the task/quiz loop with server-validated state. | Code verified; live database verification pending |
| 4 | Career accelerators: complete skill gap and vacancy matching, interview practice history, CV persistence/export, and coach proposals. Connect optional AI actions to the secured gateway with quotas and real provider responses. | Each tool uses persisted role-relevant data, clearly handles unavailable providers, and respects user consent and quotas. | In progress |
| 5 | Professional UX: settle the visual system, accessibility, responsive behavior, routes/deep links, settings, notifications, and account/data controls. Keep the island roadmap as a focused motivational feature. | Screen review across mobile/desktop, keyboard/screen-reader checks, consistent states and user-facing language. | In progress |
| 6 | Release readiness: seed real curated content, add automated quality checks and deployment configuration, observability, backup/data-retention guidance, and accurate setup docs. | Reproducible local setup and documented production deployment with verified database/function configuration. | In progress (Automated quality test suite active) |
